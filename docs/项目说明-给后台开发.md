## 1. 项目概览

包子（面包/早餐）行业信息平台小程序。用户可免费发布：招工 / 求职 / 店铺转让 / 求店 / 二手设备出售与求购 / 顺风车 / 其他；支持按区域/城市/价格/师傅类型筛选、同城"附近"、全局模糊搜索、帖子收藏、站内通知、会员（模拟）等。

- **前端**：微信小程序（`miniprogram/`），TDesign（`tdesign-miniprogram 1.9.x`），CloudBase。
- **后端**：云开发云函数（`cloudfunctions/`），NoSQL 集合。
- **后台管理**：`C:\Users\user\Downloads\shadcn-vue-admin\` —— Vue3 + TypeScript + Vite + Tailwind + shadcn-vue + TanStack Vue Query，通过 HTTP 网关调云函数 `adminAuth`。⚠️ 仓库内的 `admin/` 已废弃（旧 naive-ui 版），不要用。
- **环境**：`cloud1-9gcxv3wk28637b62`（ap-shanghai）。

## 3. 页面/功能与技术要点（写后台时有用）

- 底部导航为「首页/附近/发布/消息/我的」，用 TDesign `t-tab-bar` 组件模拟（非微信原生 tabBar）。除 demo/mine 外，7 个频道/附近/消息页用公共 `comp-tabbar`。
- 分类发布走 `publishPost`（现支持全 9 类含顺风车）；发布时区划用 `regionData.CASCADER_OPTIONS`；图片上传到云存储存 fileID 到 `image`。
- 顺风车（车找人/人找车）用独立表单 `pages/publish_carpool`，字段 `from_place/to_place/depart_time/depart_deadline/seats`，无价格；入口在顺风车频道页（右下角"发布"）、首页/我的发布弹层，以及"我的发布"与详情页的编辑路由。
- 帖子经内容安全（`secCheck`），`needs_review=false` 才展示；列表/详情/搜索都过滤待审核。
- 详情页 `pages/detail`：本人发布的帖子底部显示「编辑/删除」（按 data_type 跳对应表单页并回填）；非本人显示「收藏/查看联系方式」。归属判定用 feedPosts/`managePost.detail` 下发的 `isMine`。
- 收藏 `_openid+post_id` 唯一；我的发布/收藏/历史按 openid 归属。
- 站内通知三类：global(全局公告)/review(审核结果,定向发帖人)/member(会员开通,定向用户)；消息 tab 有未读红点。
- 会员模拟开通：`memberService.activate`（未接真实微信支付，仅演示）。
- **浏览量**：帖子详情页进入即 `managePost.view` 原子自增 `views`（前端 10 秒节流防重复）；列表卡片与详情页均展示浏览量。
- **帖子置顶**：独立集合 `baozi_post_tops`（`post_id/data_type/level/expire_at/top_type`），后台 `adminAuth.top` 设置/取消；展示端 `feedPosts` 第一页顶部插入置顶帖（已过审、未过期），并从普通列表去重。
- **老数据迁移**：`baozi_posts` 里 `source:"import_legacy"` 为历史迁移数据（约 2900 条），`_openid=""`（平台代发）、`claimed:false`、`coord_system:"bd09"`。用户认证手机号后按 `phone_normalized` 自动匹配归到其名下（`getOrCreateUser` 内完成）。迁移数据的 role/role_id/salary/月租/面积等字段已由 DeepSeek 离线补全（标 `_ai_enriched` 数组）。
